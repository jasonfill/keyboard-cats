Ten mascots, built from primitives

Every character here is assembled from circles, rounded rectangles and triangles only — no traced curves. That is a deliberate style choice, not a limitation: it keeps ten characters visually consistent, guarantees they survive 34px, and it is a style you can ship as v1. If you later commission drawn versions, these fix the pose, proportion and palette so the illustrator has nothing to invent. One deliberate break from what ships today: the current CatMascot is a head only, so all ten of these are full-body replacements rather than matches — the 200px hero slot needs a posture, and nine new characters need one rule.

What holds them together

Same primitive kit, same ground shadow, same three-flats-plus-one-shade palette drawn from each theme accent. Head-to-body ratio is constant. Nobody holds a pencil, wears glasses, or carries signage, so nothing needs redrawing to localise — and Spark orange never appears, because it belongs to the brand and its buttons.

Honest limits

Primitives get you character and consistency, not charm — a drawn cat will always beat an assembled one. These also carry only the idle pose; cheer, thinking and resting need building, and the three reward-art sets are a much larger job. Ship these as v1 if you want ten themes live now, and commission drawn replacements theme by theme.
